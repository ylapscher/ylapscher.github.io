# Portfolio — Joe Lapscher

Websites and product work Joe Lapscher has shipped.

- [Sam Storybook](https://lapscher.com/portfolio/sam-storybook.md): Families order a personalized photo storybook online. Stripe checkout, then a printed book in the mail.
- [Knock on Block](https://lapscher.com/portfolio/knock-on-block.md): A local handyman's site: services, work photos, and a quote form that emails the owner the moment someone asks.
- [Yoga Studio](https://lapscher.com/portfolio/yoga-studio.md): A free pose library and sequence builder for home practice. Works offline as a PWA, no subscription.
- [Harbor Parking](https://lapscher.com/portfolio/harbor-parking.md): Replaced a building's WhatsApp parking thread with a live availability board and reservations.

More context on each project lives at the `.md` URL next to the title.
