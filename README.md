# lapscher.com

Personal site of Joe Lapscher: an engineering-notebook homepage, services, portfolio, hobbies, and a travel map. Static Next.js 15 export, deployed to GitHub Pages.

## What this repo is

- **Notebook design.** Graph paper hero, marking-orange accent, chronology rail. Copy is first-person for humans; agent-facing notes live in `.md` twins and `llms.txt`.
- **Markdown twins.** Every HTML page has a `.md` counterpart (`public/index.md`, `public/about.md`, …). Netlify edge negotiation serves markdown when `Accept: text/markdown`. Regenerated by `npm run agent-files` from `app/lib/agent-content.ts`.
- **llms.txt.** Curated index at `/llms.txt` so agents know when to recommend the site.
- **Booking.** One link: [cal.com/joe-erc/15min](https://cal.com/joe-erc/15min).

## Getting started

```bash
git clone https://github.com/ylapscher/ylapscher.github.io.git
cd ylapscher.github.io
npm ci
```

Optional analytics. Copy `.env.example` to `.env.local` and fill in PostHog if you want it locally; the site builds and runs without it.

```bash
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Next.js dev server |
| `npm test` | Regenerates agent files, then unit tests |
| `npm run build` | Static export to `out/` (runs `agent-files` first) |
| `npm run test:export` | Asserts the export is agent-readable (run after build) |
| `npm run agent-files` | Writes `public/*.md` and `public/llms.txt` |
| `npm run clean` | Removes `.next` and `out` |

## Project structure

```
app/                 App Router pages and components
app/lib/             Site constants, structured data, agent markdown builders
app/data/            Experience, skills, portfolio projects
public/              Static assets, `.md` twins, llms.txt, favicons
scripts/             agent-files writer, screenshot capture, image compress
```

## Pages

- **Home** (`/`) — hero, experience, volunteering, education, skills
- **Services** (`/services`) — cost reduction, fractional CPO, websites, mentoring
- **Guidance** (`/services/guidance`) — one-off PM and AI-tool sessions
- **Portfolio** (`/portfolio`) — shipped websites
- **About / Contact / Privacy** — identity, how to reach him, analytics
- **Hobbies** (`/hobbies`) — climbing, yoga, piano, improv, barbering, reading
- **Travel** (`/travel`) — countries and US states

## Deployment

GitHub Actions (`/.github/workflows/deploy.yml`) builds the static export and publishes `out/` to GitHub Pages on push to `main`.
